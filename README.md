# 🎓 Student Task Planner

A simple web application that helps students organize and manage their daily tasks.

## ✨ Features
- Add and delete tasks
- Set due dates
- Choose High, Medium, or Low priority
- Mark tasks as completed
- Track total, completed, and pending tasks
- Automatically save tasks using browser localStorage

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Download this repository.
2. Open `index.html` in your web browser.
3. Start managing your tasks!

## 👩‍💻 About
This is my beginner web development project, created to practice HTML, CSS, JavaScript, and browser storage.
